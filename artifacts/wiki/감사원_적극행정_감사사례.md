## 개요
- **컬렉션명:** 감사원_적극행정_감사사례  
- **대상:** 감사원 공식 적극행정지원 사이트의 **면책사례** 및 **사전컨설팅 처리사례**를 문서 단위 Markdown으로 정리한 데이터셋
- **문서 수:** 540

## 포함 데이터
- 감사원 면책사례: **98건**
- 감사원 사전컨설팅 처리사례: **318건**
- 자체감사기구 면책사례: **44건**
- 자체감사기구 사전컨설팅 처리사례: **80건**

### 파일 구조
- `kr/{게시판명}/{게시글ID}/사례.md` : 사례별 Markdown 본문
- `index.jsonl` : 문서 경로, 제목, 게시판, 등록일, 출처 URL 색인

## 주요 활용 질문
- “유사한 **사례 제목/쟁점**(예: 수의계약, 예산집행, 공유재산 처리 등)이 있을 때, **검토 결과/인정 여부**는 어떻게 정리되어 있는가?”
- “면책사례와 사전컨설팅 처리사례에서 **판단 근거(지적 사항, 신청 취지, 인정 여부, 검토 결과 등)**가 어떻게 분리되어 있는가?”
- “특정 주제(예: 계약/발주, 공유재산, 예산 집행, 인허가 등)로 **유사사례 추천**을 할 수 있는가?”

## 탐색 시작점
- 먼저 **색인**을 사용: `index.jsonl`
  - 필요 필드: 문서 경로, 제목, 게시판, 등록일, 출처 URL
