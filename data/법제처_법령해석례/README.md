# 법제처 법령해석례

우리금융지주 PoC용으로 외부 공개 사이트에서 수집한 법제처 법령해석례 Markdown 데이터입니다.

## 선정 이유

이미 보유한 법령 원문만으로는 실제 질의에 대한 적용 판단 근거가 부족합니다. 법제처 법령해석례는 질의요지, 회답, 이유, 관계 법령을 함께 포함하므로 RAG에서 “어떤 조문을 어떻게 해석해야 하는지”를 보강하는 데 가장 직접적인 성능 향상이 기대됩니다.

## 구조

```text
kr/
  {안건번호}/
    법령해석례.md
index.jsonl
```

각 Markdown 파일은 `legalize-kr/legalize-kr`처럼 YAML frontmatter와 본문 Markdown으로 구성됩니다.
