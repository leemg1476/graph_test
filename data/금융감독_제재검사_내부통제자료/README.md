# 금융감독 제재·검사·내부통제 자료

금융회사 내부통제 미비, 제재 의결, 검사결과, 내부통제 제도개선 관련 공개자료를 Markdown으로 정리한 데이터셋입니다.

## 수집 자료

- 대구은행에 대한 금융위원회 제재 의결 (제재공시/보도참고)
- 금융권 내부통제 제도개선 방안 발표 (검사제재/내부통제 제도자료)
- 금융권 내부통제 제도개선 TF 중간논의 결과 (검사제재/내부통제 제도자료)
- 금융회사 내부통제 강화방안 (검사제재/내부통제 제도자료)
- 금융회사 직원들이 연루된 미공개중요정보 이용행위 적발 (검사결과/불공정거래)
- 비대면 계좌개설 안심차단 서비스 시행 (계좌개설 통제 제도자료)
- 경남은행 횡령사고에 대한 검사결과 잠정 (검사결과)
- 제20차 금융위원회 의사록 경남은행 PF대출 내부통제 (제재공시/의사록)
- 제2차 금융위원회 의사록 내부통제 기준 미마련 (제재공시/의사록)
- 내부통제 제도개선 방안 첨부자료 (검사제재/내부통제 제도자료)
