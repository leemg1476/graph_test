# 감사원 적극행정 감사사례

감사원 공식 적극행정지원 사이트의 면책사례 및 사전컨설팅 처리사례를 `legalize-kr/legalize-kr` 저장소처럼 문서 단위 Markdown으로 정리한 데이터셋입니다.

## 수집 범위

- 감사원 면책사례: 98건
- 감사원 사전컨설팅 처리사례: 318건
- 자체감사기구 면책사례: 44건
- 자체감사기구 사전컨설팅 처리사례: 80건

## 구조

- `kr/{게시판명}/{게시글ID}/사례.md`: 사례별 Markdown 본문
- `index.jsonl`: 문서 경로, 제목, 게시판, 등록일, 출처 URL 색인

## RAG 활용 메모

감사 사례는 지적 사항, 신청 취지, 인정 여부, 검토 결과처럼 판단 근거가 분리되어 있어 내부 규정 질의응답, 감사 대응 근거 검색, 유사사례 추천에 직접 활용하기 좋습니다.
